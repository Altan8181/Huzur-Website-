# Huzur & Co

Einseitige Website für die Duftkerzen-Marke Huzur & Co (reines HTML/CSS, kein Build nötig).

- `index.html` – Seite (Hero, Produkte, Über uns, Kontakt)
- `styles.css` – Gestaltung

Lokal ansehen: `index.html` im Browser öffnen.

Kontaktformular: Für echten Versand im `<form>` das Attribut `action` auf einen Formular-Dienst (z. B. Formspree) setzen.
